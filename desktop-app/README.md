# 💻 تطبيق إدهام ERP للديسكتوب (Electron Wrapper)

تطبيق ديسكتوب خفيف لتشغيل وإدارة نظام إدهام ERP مباشرة من سطح المكتب مع الحفاظ على التزامن السحابي الكامل مع المندوب مصطفى في الميدان.

---

## 🚀 طريقة التشغيل المحلية (للتطوير أو التجربة):

1. افتح نافذة الأوامر (PowerShell أو CMD) في مجلد التطبيق:
   ```bash
   cd "e:\ادهام للمواد الغذائية\desktop-app"
   ```

2. قم بتثبيت الاعتماديات المطلوبة (تُشغَّل لأول مرة فقط):
   ```bash
   npm install
   ```

3. قم بتشغيل التطبيق مباشرة:
   ```bash
   npm start
   ```

---

## 📦 طريقة حزم وصنع ملف تثبيت ديسكتوب (EXE.):

لصنع ملف تثبيت مستقل بصيغة `exe` لتثبيته على أي جهاز ويندوز دون الحاجة لفتح الكود:

1. قم بتثبيت حزمة البناء `electron-builder` كاعتمادية تطوير:
   ```bash
   npm install --save-dev electron-builder
   ```

2. قم بتشغيل أمر الحزم والتجميع:
   ```bash
   npx electron-builder --windows
   ```

3. بعد اكتمال البناء، ستجد ملف التثبيت المجمع للويندوز داخل مجلد جديد باسم `dist/` داخل مجلد `desktop-app/`.
