# 04 — محرك القيود المحاسبية التلقائية

## نظرة عامة

**الملف:** `js/utils/accounting-engine.js` (43 KB)

محرك القيود (Accounting Engine) هو قلب النظام المحاسبي. كل عملية تشغيلية تُولّد قيدها المحاسبي تلقائياً بدون أي تدخل يدوي. يعتمد على مبدأ **القيد المزدوج (Double-Entry Bookkeeping)**.

---

## القيود التلقائية لكل عملية

### 1️⃣ فاتورة بيع آجلة (Credit Sale)
```
مدين   ذمم عملاء تجزئة (1-1-2-1-1)          172.50
دائن   مبيعات تجزئة - آجل (4-1-1-1-3)       150.00
دائن   ضريبة مخرجات (2-1-3-1)                22.50

--- وقيد تكلفة البضاعة المباعة ---
مدين   تكلفة البضاعة المباعة (5-1-8)         80.00
```

## آلية تحديث الأرصدة

```
عند حفظ قيد محاسبي:
1. كل بند في القيد → يُحدَّث رصيد الحساب في chartOfAccounts
2. الحسابات الأب → تُجمَع أرصدة الأبناء تلقائياً
3. balance في customer/supplier → يُحدَّث من مجموع قيوده

الصيغة:
  لحسابات الأصول والمصروفات: balance = مجموع المدين - مجموع الدائن
  لحسابات الخصوم والإيرادات: balance = مجموع الدائن - مجموع المدين
```

## ميزان المراجعة (Trial Balance)

### هيكل ميزان المراجعة:

```
حساب الأب (مثال: 1 - الأصول)
  ├── 1-1 الأصول المتداولة
  │   ├── 1-1-1 النقدية وما يعادلها    مدين: 65,000   دائن: 0
  │   ├── 1-1-2 الذمم المدينة          مدين: 25,000   دائن: 0
  │   ├── 1-1-4 المخزون               مدين: 86,000   دائن: 0
  │   └── 1-1-5 أصول أخرى            مدين: 0        دائن: 0
  └── [الإجمالي]                       مدين: 176,000  دائن: 0

الإجمالي الكلي يجب أن يكون:
  إجمالي المدين = إجمالي الدائن  ✓
```

## التحقق من صحة القيد

```javascript
// قبل الحفظ:
const totalDebit  = lines.reduce((s, l) => s + (l.debit  || 0), 0);
const totalCredit = lines.reduce((s, l) => s + (l.credit || 0), 0);
const isBalanced  = Math.abs(totalDebit - totalCredit) < 0.01;

if (!isBalanced) {
  throw new Error("القيد غير متوازن: المدين ≠ الدائن");
}
```
